TROUBLESHOOTING

Problem: Site not accessible
Solution: 
  1. Check IIS is running: iisreset /status
  2. Verify site status: Get-Website -Name 'Strat-IQ-Azure-Proxy'
  3. Check Azure connectivity: ping strat-iq.azurewebsites.net

Problem: 500 Error
Solution:
  1. Check Application Pool: Get-WebAppPoolState -Name 'Strat-IQ-Azure-Proxy'
  2. Review IIS logs: %SystemDrive%\inetpub\logs\LogFiles
  3. Verify web.config: LaunchModules/azure-proxy-root/web.config

Problem: Slow response
Solution:
  1. Check Azure Service performance
  2. Monitor IIS Worker Processes (CPU/Memory)
  3. Verify network connectivity
  4. Check compression settings in web.config

PROXY ROUTING

All Requests to http://localhost:8096/*
        ↓
Are proxied to https://strat-iq.azurewebsites.net/*

Redirect responses are rewritten:
  https://strat-iq.azurewebsites.net/path
        ↓
  http://localhost:8096/path

This ensures seamless transparent proxying.

   - Disable idle timeout: No cold starts
   - Monitor CPU/Memory: Use IIS Manager

2. Web.config Compression
   - Enabled for text/json
   - Reduces bandwidth usage
   - Transparent to clients

3. Azure Backend
   - Keep Azure Service healthy
   - Monitor response times
   - Scale Azure tier if needed
