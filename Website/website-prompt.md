# Best Prompt for the Strat-Aqorynth Website

Use this prompt to regenerate or refine the product website from the repository features.

```text
Build a polished, production-ready website for "Strat-Aqorynth", a multi-module enterprise AI platform. The site must feel like an executive-grade product website for CIOs, CTOs, enterprise architects, modernization leaders, IT operations leaders, and innovation/IP stakeholders.

Use the project feature inventory below as ground truth. Do not invent unrelated modules. Position Strat-Aqorynth as a local-LLM-first, deterministic-fallback enterprise platform for IT application rationalization, code modernization, infrastructure discovery, grounded incident-resolution RAG, ITSM automation ROI, robot digital twins, secure SDLC assessment, financial/tower consolidation, opportunity tracking, remanufacturing scoring, vehicle-loan prequalification, and supply-chain disruption response.

Required website structure:
1. Hero section:
   - Headline: one clear statement that Strat-Aqorynth rationalizes, modernizes, and operates complex IT estates.
   - Supporting copy: mention 13 independently deployable modules, local AI, deterministic fallbacks, audit-ready outputs, and unified enterprise portal.
   - Include strong calls to action such as "Explore modules" and "View architecture".
   - Use a serious enterprise visual: operations command center, infrastructure topology, code analysis, RAG evidence, robotics, and supply-chain signals. Avoid cartoon style, generic stock imagery, purple gradients, decorative blobs, and empty marketing fluff.

2. Platform thesis section:
   - Explain the recurring architectural pattern: LLM-assisted where judgment matters, deterministic where correctness matters.
   - Include three pillars: Local-first AI, Deterministic fallbacks, Audit-ready outputs.

3. Module suite section:
   - Present all 13 modules as scannable cards.
   - Include filters or categories: Modernization, Operations, Governance, Prototype.
   - Each card needs a concise value proposition based on the actual feature set.

Module facts:
- AppRationalization: cascading multi-source entity resolution, golden records, hybrid rule/LLM 4R disposition scoring.
- CodeAnalysis: multi-language static analysis, COCOMO II technical debt costing, defect prediction, CO2 estimation, knowledge/call graphs, LLM grounding against incompatible modernization recommendations.
- InfraRationalization: agentless discovery, SNMP topology, PDF/OCR asset extraction, dependency wave planning, RTO/RPO feasibility, decommissioning, hypervisor consolidation, Terraform/ARM/CloudFormation generation.
- Modernization: persona-routed multi-target code transpilation, adaptive context sizing, content-hash caching, domain-driven decomposition, VS Code/GitHub Copilot Chat participant.
- Novastra-ITSM: 11-stage grounded RAG pipeline with metadata lookup, multi-angle retrieval, keyword/entity search, sibling augmentation, cross-encoder reranking, evidence gates, regex-first extraction, direct-answer short-circuiting, post-generation validation, context-only prompting, temperature-zero deterministic generation.
- Dashboard: executive ITSM intelligence, deterministic 100-point automation-opportunity score, estimated hours/cost saved, local LLM enrichment, in-memory cache and offline fallback.
- LabRobot: physics-based robot fleet digital twin, MQTT command bridge, idempotent queue, ack-gated inventory reconciliation, collision-aware pathing, battery modeling.
- SSDLC_Process_Assessment / CSM: weighted secure-SDLC maturity scoring with constrained LLM output contract, no fabricated score when LLM is offline, CISO briefing generation, formula-level audit trail for consolidation savings with Decimal rounding.
- OpportunityTracker: deterministic/LLM-split migration wave planning, regex veto override, bin-packing wave assignment, deterministic rationale strings, custom signed token.
- AI_Reman_Core: remanufactured-parts defect-penalty life and warranty tiering schema; prototype, scoring schema only.
- AI_Vehicle_Loan: conversational vehicle loan prequalification with deterministic risk tiering, regex intent routing, token-overlap vehicle discovery; prototype/stubbed data.
- Microsite_Data_Analysis: tower consolidation studio, spreadsheet-to-SPA formula migration, vendor rationalization heatmap, reinvestment allocation.
- Supply Chain Disruption Manager: sense-understand-act multi-agent platform, canonical signal normalization, YAML severity rules, Redis dedupe, Neo4j blast-radius traversal, specialist agent orchestration, irreversible-action human approval gates.

4. Architecture section:
   - Show "Data in -> Strat-Aqorynth core -> Decisions out".
   - Data in: CAST exports, CMDB PDFs, network scans, repositories, ITSM tickets, spreadsheets, robot telemetry, ERP/WMS/TMS/MES events.
   - Core: shared auth, module APIs, local LLM services, deterministic scorers, vector stores, graph services, formula engines, IIS/deployment automation.
   - Decisions out: 4R dispositions, modernization reports, migration waves, IaC, grounded answers, automation backlog, audit trails, governed actions.

5. Status / maturity section:
   - Make clear that most modules are production use.
   - Identify AI_Reman_Core and AI_Vehicle_Loan as prototypes with scoped claims.
   - Call out Novastra-ITSM and Supply Chain Disruption Manager as the strongest platform differentiators.

Design requirements:
- Use a restrained enterprise UI: clean typography, strong hierarchy, responsive layout, high information density, 8px or smaller card radius.
- Do not create a generic SaaS landing page full of vague claims.
- Avoid nested cards, decorative gradient blobs, one-note purple/blue palettes, unreadable text, and oversized copy inside compact cards.
- Use visual assets that communicate the actual platform.
- Make the first viewport immediately show the Strat-Aqorynth brand and product category.
- Ensure mobile and desktop layouts have no overlapping text.

Technical requirements:
- If building static output, create index.html, styles.css, script.js, and an assets folder.
- If building React/Vite, create componentized sections and keep data-driven module cards in one array.
- Include accessible alt text, semantic headings, and keyboard-friendly controls.
- The finished site should be easy to deploy behind IIS or open locally.
```
